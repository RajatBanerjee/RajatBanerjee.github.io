01. About

I started out writing code — Node.js services, React frontends, the full stack. Somewhere along the way I realized I got just as much energy from unblocking other engineers as I did from shipping my own features. That shift led me from senior IC work into engineering management.

Today I run the teams behind Fanatics' homegrown CRM and CMS platforms. We own the systems that decide which message reaches which fan, across web and email — at a scale that keeps things interesting.

Having spent a decade writing production code before managing people, I lead with technical context. I can review a system design and a sprint retro with equal fluency, and I think that matters.
